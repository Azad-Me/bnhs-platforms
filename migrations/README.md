# Database migrations

Install the migration dependencies from the repository root:

```powershell
python -m pip install -r requirements.txt
```

Configure the connection with `DB_HOST`, `DB_PORT`, `DB_USERNAME`,
`DB_PASSWORD`, and `DB_NAME`. The defaults match `DatabaseSettings`.

Apply migrations to an empty database:

```powershell
alembic upgrade head
```

Create a migration after changing the SQLAlchemy models:

```powershell
alembic revision --autogenerate -m "describe the change"
```

Review autogenerated migrations before applying them. Alembic does not detect
PostgreSQL trigger or function changes automatically; add those operations to
migrations explicitly.

For a database that already has this schema, verify that it matches the initial
migration before marking it as applied:

```powershell
alembic stamp head
```

`stamp` only updates Alembic's version table; it does not create or alter the
application schema.
